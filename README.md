# revenueandbeyond.com

The live website, as static files. Netlify publishes the `site/` folder on every push to `main` (see `netlify.toml`). There is no build step.

- `site/` the website exactly as served. Edit pages here.
- `tools/add_insight.py` adds a newsletter issue to the Insights section (new page, top of the Insights list, sitemap). Used by the Monday scheduled task after each Sunday Founder Read send.

Seeded on 16 Oct 2026 from the published Netlify deploy of 10 Oct 2026 (deploy 6aca63f1f7fe4fba91f373d6).

Rules
- Every change goes through this repo. Netlify Drop uploads would be overwritten by the next push.
- Keep the hidden pre-engagement form page and any other unlinked pages inside `site/`, or they disappear on the next deploy.

Private deal pipeline
- Page: `site/pipeline-x8k3vq/` (unlisted, noindex, not in the sitemap). Opens behind a passcode.
- API: `netlify/functions/pipeline.mjs` at `/api/pipeline`. Checks the `x-pipeline-key` header against the Netlify environment variable `PIPELINE_PASSCODE`; without that variable set it refuses every request.
- Storage: Netlify Blobs (store `pipeline`, key `board`). Simon's edits live there, not in this repo.
- Weekly sweep: `data/pipeline-feed.json` (outside `site/`, bundled into the function, never served). The Monday scheduled task rewrites this file and pushes. On the next load the board adds new deals, updates deals Simon has not touched, and shows changes to deals he has edited as suggestions. Deleted deals are never re-added.
- Newsletter: deal emails are added to The Founder Read (beehiiv) with the welcome email, unless a deal is set to "Don't add". Needs Netlify env vars `BEEHIIV_API_KEY` and `BEEHIIV_PUBLICATION_ID` (pub_380dc75b-af45-4f44-94ee-572a61f272d9). Each address is submitted once; unsubscribed people are never reactivated.

Founder-led sales blueprint (lead magnet)
- Gated page: `site/blueprint/` (in the sitemap). Email form posts to `/api/blueprint` (`netlify/functions/blueprint.mjs`), which saves every lead in Netlify Blobs (store `leads`) and adds them to The Founder Read on beehiiv (utm_source `blueprint`, welcome email on), using the same `BEEHIIV_API_KEY` and `BEEHIIV_PUBLICATION_ID` variables as the pipeline.
- Open page for newsletter readers, free to share: `site/blueprint/download/` (noindex, not in the sitemap or nav).
- The PDF: `site/assets/downloads/founder-led-sales-blueprint.pdf`. To update the guide, replace this file with the same name and push.
- Pages are generated by `tools/blueprint_pages.py` from the newsletter page shell.
